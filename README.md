# Tetris

素のHTML/CSS/JSで作ったテトリス風ゲーム。ビルド不要の静的サイトなので、そのままホスティングサービスにデプロイできます。

## ローカルで遊ぶ

`index.html` をブラウザで直接開くか、簡易サーバーを立てて確認してください。

```bash
npx serve .
```

## 操作方法

| キー | 動作 |
| --- | --- |
| ← / → | 左右移動 |
| ↓ | ソフトドロップ |
| ↑ / X | 右回転 |
| Z | 左回転 |
| Space | ハードドロップ |
| C | ホールド |
| P | ポーズ |

スマホ・タブレットでは画面下のタッチボタンが表示されます。

## 公開手順(例)

### GitHub Pages
1. このフォルダをGitHubリポジトリにpushする
2. リポジトリの Settings → Pages で、公開ブランチとルートディレクトリを指定する
3. 発行されたURLで公開完了

### Netlify / Vercel
1. リポジトリをNetlify/Vercelに連携する
2. ビルドコマンドは不要(空欄)、公開ディレクトリはルート( `.` )を指定する
3. デプロイ実行で公開完了

## 構成

- `index.html` — マークアップ
- `style.css` — 見た目
- `script.js` — ゲームロジック(7-bagランダム、ホールド、次ピース3手表示、ゴースト表示、レベル/スコア/ハイスコア管理)
